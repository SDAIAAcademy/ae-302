The numbers the README reports

  • At least 15 tasks, five trials each, graded by code, response cache off.
  • An error analysis: the causes counted, and what flipped between A and B.

pass^5 is the share of tasks passed in every trial; pass@5 in any trial. Cost per completed task is the total cost divided by the passed runs, so a cheap agent that fails often is not cheap. Free models report zero cost: then report tokens per completed task as well.

Evidence: a logged injection run in which exfiltration fails, with tool results logged by size, not content.

The starter has no exit path and no contact data, so the attack has nowhere to go. Participants who add one (an email tool, a booking list) must show the leg they removed and the log. A defence that depends on the model noticing scores low under containment.

Pass: 70% overall, and at least 60% on this rubric. The repository is 60% of the result, the defence 20%, the supervised checks 20%.

Reproducibility means a clean clone runs with uv run and a key, and every number in the README is backed by a committed file. Authenticity evidence: timestamped agent transcripts and run logs, plus the defence.

The defence

Eight minutes: the numbers, a live run, one failure

2 min · the design

The problem, the harness, the table of trials.

3 min · a live run

The assessor gives a task you have not seen; run it.

3 min · one failure

From a trace: what the agent saw, did, and what would prevent it.

AI-full. Coding agents were allowed; the defence is where you show the decisions are yours.

Assessors: keep a short list of unseen research questions answerable from the circulars. If the live run fails, that is the failure to explain: a calm reading of the trace scores well.

Final preparation

Ten minutes: clone it clean, run one task

Clone your public repository into a new folder and run one task from its README. If that fails, the assessor's will too.

The clean-clone test catches most reproducibility losses: a missing data file, a key in a local file, a path that only exists on the participant's laptop.
