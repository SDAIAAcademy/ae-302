The decision

Split when the jobs differ in context, permissions or time

  • The research reads far more than the reply needs.
  • The jobs need different permissions: the drafter must never see the booking list.
  • Research runs in parallel over several sources.
  • Not when the task is short and the notes would carry everything anyway.

Tie the second bullet to Session 3: splitting is also a containment tool, because the agent that reads untrusted text need not hold private data. Agent-to-agent protocols hand over a task with a status rather than a function call; the stretch makes the researcher return one.

Production

An agent in production is a service with limits

Endpoint

An API key that decides the agent code; a token budget per session.

Traces

A span per request and per tool call, sent to a collector.

Gate

A smoke evaluation in CI that stops a release that got worse.

Lab 4.4 builds all three in-process with FastAPI's TestClient and an in-memory span exporter. The entry's tool slots name FastAPI, GitHub Actions or GitLab CI, and OpenTelemetry with a collector such as Langfuse or Arize Phoenix: interchangeable examples.

def ask(body: Ask, x_api_key: str = Header(default="")):
    if x_api_key not in KEYS:

    code = KEYS[x_api_key]               # NJM-4417 for Najm's key
    if used[session] >= budget_tokens:

If the body carried the agent code, any caller could act for any agent. The course's run returned 401 for an unknown key and a 200 with SAR 7,800 for Najm Falcon (scripted model, real tools).
